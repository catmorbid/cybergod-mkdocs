`Cost: 1 Effect Point, Repeatable`

All [[systems/psionics/index|Psionic]] **Effects** have various basic properties, such as *Damage Class*, *Duration* or *Range*, which can be boosted by taking the **Potency effect**. Potency effects are repeatable and can be *stacked* indefinitely. Each individual *stack* improves exactly one property by one step. You can apply multiple stacks across different properties. 

Modifiable properties are indicated by arrows **’→’**. Each **‘→’** represents one potential increment in a property. Properties without further arrows cannot be improved beyond their listed maximum.

When using [[#Combined Effects]]:
- If properties of combined Effects are in conflict, simply use the highest property on each

>E.g. a *Moderate* *radius* property and a *Short radius* property would be combined to the better *Moderate radius* property.

Each Potency stack affects only one property at a time, but you may apply as many Potency stacks as desired. Different property improvements all apply simultaneously, so you may, for instance, increase both _Range_ and _Target count_ with different Potency stacks.


!!! example
	A psionic effect has the following modifiable properties:
	- **DC:** 5 → 6 → 7
	- **Targets:** 1 → 2→ 3
	- **Range:** Short → Moderate → Long
	
	 A Psionic spends 3 *Potency* effects improving DC to 7 (stack 2) and Targets to 2 (stack 1). The psionic can now inflicts DC 7 damage to 2 different targets, both within Short range.
