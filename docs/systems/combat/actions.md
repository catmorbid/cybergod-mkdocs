title: Actions
version: 1
---
Each character has **1 Action** and **1 Reaction** during their combat [[turns|turn]]. They are mutually inclusive and any action can also be taken as a reaction. An action can be anything that takes roughly 1-2 seconds.

| Action                                | Summary                                                                                                        |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [[action-attack\|Attack]]             | Take offensive action in either [[close-combat\|Close Combat]] or [[ranged-combat-v4\|Ranged Combat]]       |
| [[action-aim\|Aim]]                   | Aim before attack. Allows adding weapon **CTRL** Dice as Utility (depending on fire mode).                     |
| [[action-move-evade\|Move and Evade]] | Move around the battlefield and take evasive actions.                                                          |
| [[cover-v4\|Take Cover]]              | Find suitable cover and utilize it to avoid Hits.                                                              |
| Change Stance                         | E.g. Stand up from prone position. Anything that takes a modicum of effort.                                    |
| Activate Augment                      | Activate an augment that requires activation *as an Action*.                                                   |
| Operate                               | Operate machinery, equipment or remote-controlled drones                                                       |
| Field Medical Aid                     | Administer [[damage-healing\|Healing]] in field conditions.                                                    |
| Use Item                              | Use an Item that is prepared. You can spend an *Instant* *Action* to prepare items that are readily available. |
| Prepare Item                          | Prepare an item or equipment to be used when it is not *readily available*, e.g. draw a holstered weapon or    |
