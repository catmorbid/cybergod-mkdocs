title: Damage System
version: 1
---
Resolve Damage by following the procedure laid out in these steps:

1. Determine number of *Hits* generated by *Effects*.
2. Determine [[damage-class|Damage Class (DC)]] and apply [[damage-mitigation|Damage Mitigation]]
3. *(Optional) Apply [[damage-class#Optional Rule Simplified damage|Simplified Damage]] rule*
4. *(Default)* Make the [[damage-roll|Damage Roll]]
5. Determine [[damage-conditions|Damage Conditions]]
6. Note any additional [[systems/conditions/index|Conditions]]
7. Accumulate [[damage-pain|Pain]]
