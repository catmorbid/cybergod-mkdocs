---
title: Recovery Test
version: 1
---

During upkeep phase, you may make a Recovery Test. Normally you can heal Shock and removed Stunned condition, but when augments are activated it becomes possible to recover from more serious damage and conditions.

**System**

Test `Mind + Toughness` and spend Effect Points according to the following table:

| Effect            | Cost | Description                                                                                                                                                |
| ----------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Recover Shock     | 1R   | When **not** [[condition-stunned\|Stunned]]. Repeatable. Recover a **Shock** condition.                                                                    |
| Recover Stunned   | 3    | When [[condition-stunned\|Stunned]]. Remove Stunned Condition and recover 1 Shock.                                                                         |
| Tolerate Pain     | 2R   | Repeatable. Ignore 1 level of **Pain**.                                                                                                                    |
| Fight Through     | 4    | When **incapacitated** or **collapsed**. Remain active for one more turn. The states persist and if you fail, you’re out for good and unable to try again. |
| Regenerate Harm   | 2R   | When **regenerating**. Heal **Harm** condition                                                                                                             |
| Regenerate Trauma | 5R   | When **regenerating**. Heal **Trauma** condition                                                                                                           |
| Regenerate Fatal  | 10R  | When **regenerating**. Heal **Fatal** condition                                                                                                            |
*Recovery Test Effects table* `R` = repeatable
