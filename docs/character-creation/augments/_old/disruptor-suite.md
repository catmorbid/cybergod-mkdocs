An asymmetric warfare system that allows disruption of communications, electronics and augmentations. Designed for anti-cyborg warfare, the **Disruptor Suite** can be a powerful tool that enhances tactics and weakens powerful augment-reliant cyborgs.

| Level | Effect                                                                                                                                                                                |
| :---- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1     | **Electronic Camouflage**: Test `Stealth + Cyber` to conceal up to 2 targets from electronic surveillance without penalties. Apply `DIF 1` complication for every 2 targets beyond 2. |
| 1     | **Interference Detection**:Test `Alertness + Cyber` to detect use of Interference.                                                                                                    |
| 2     | **Augment Interference**: Disrupt a random augment → choose 1 augment on target. The augment is disabled for **Short** → **Moderate** duration.                                       |
| 2     | **Electronic Disruption**: Block communications within **Long** → **Extreme** distance radius.                                                                                        |
| 3     | **Electronic Hijack**: You can hijack any wireless communications within **Long** → **Extreme** radius.                                                                               |
| 3     | **Short Circuit**: If target activates any augments for **Moderate** duration, they take a Major Wound.                                                                               |
